# VSM(Vehicle Speed Monitor) 요구사항 명세 — 교육용 축약본

가상 시나리오입니다. 실습 예제 코드가 "무엇과 대조되어야 하는가"의 기준(룰북)을 제공하기 위한
최소 명세이며, 3일차 V-SPICE 추적성 실습과 접합할 수 있도록 ID 를 부여했습니다.

## 1. 개요

VSM 은 차속 센서 값을 주기적으로 읽어 잡음을 제거하고, 차속에 따라 경고 등급을 판정하여
진단 이력에 기록하는 ECU 소프트웨어 컴포넌트다.

## 1-1. 용어

| 용어 | 뜻 | 근거 |
|---|---|---|
| 차속 | 차량의 속도이며, 단위는 km/h 이다. | 1절 · SR-001 |
| 센서 값 · 샘플 | 차속 센서가 읽은 차속 값 하나를 말한다. 범위와 단위는 차속과 같다. | 1절 · `sensor_filter.h` 「차속 센서 값 필터링」 |
| 경고 등급 | 차속에 따라 판정하는 `NONE` · `LOW` · `MID` · `HIGH` 네 등급을 말한다. | §3 |
| 과속 카운터 | 경고 등급을 `HIGH` 로 판정한 횟수를 센 값이다. | SR-010 |

## 2. 기능 요구사항

| ID | 요구사항 | 관련 구현 |
|---|---|---|
| SR-001 | VSM 은 차속을 0 ~ 65535 km/h 범위의 부호 없는 정수로 취급해야 한다. | `vsm_types.h` |
| SR-002 | 차속이 **200 km/h 이상**이면 경고 등급을 `HIGH` 로 판정해야 한다. | `sm_evaluate()` |
| SR-003 | 차속이 150 km/h 초과 200 km/h 미만이면 경고 등급을 `MID` 로 판정해야 한다. | `sm_evaluate()` |
| SR-004 | 센서 값은 최근 8개를 링 버퍼에 유지해야 한다. | `sf_push()` |
| SR-005 | 과속 카운터는 `sm_reset()` 호출로 초기화되며, 대상 ECU 는 인자로 지정된다. | `sm_reset()` |
| SR-006 | 판정된 경고 등급은 매 주기 진단 이력에 기록되어야 한다. | `dl_record()` |
| SR-007 | 센서 평균은 넣은 샘플들의 산술 평균이며, 소수점 이하는 버린다. | `sf_average()` |
| SR-008 | 평균을 구하는 샘플 개수는 1 개 이상 8 개 이하이다 (SR-004 의 버퍼 크기). | `sf_average()` |
| SR-009 | `sf_latest()` 는 가장 최근에 `sf_push()` 로 넣은 센서 값을 돌려주어야 한다. | `sf_latest()` |
| SR-010 | 과속 카운터는 경고 등급을 `HIGH` 로 판정할 때마다 1 씩 늘고, 최대값(4294967295)에 이르면 더 늘지 않아야 한다. | `sm_evaluate()` · `sm_over_count()` |
| SR-011 | 임계값 문자열이 숫자로 해석되지 않으면 -1 을 돌려주어야 한다. | `dl_parse_threshold()` |
| SR-012 | 직전 주기 차속에서 현재 차속을 뺀 감소량이 **30 km/h 이상**이면 급감속으로 판정해야 한다. 차속이 같거나 늘었으면 급감속이 아니다. | `sm_is_sudden_drop()` |

## 3. 경고 등급 정의

| 등급 | 의미 | 판정 조건 |
|---|---|---|
| `NONE` | 정상 | 차속 0 km/h |
| `LOW` | 주의 없음 | 0 < 차속 ≤ 150 km/h |
| `MID` | 주의 | 150 < 차속 < 200 km/h |
| `HIGH` | 경고 | 차속 ≥ 200 km/h (SR-002) |
